# 验收矩阵

下表保留完整验收要求。参考 alpha 的适用项已有 64 项公开测试通过（零跳过），实际证据及限制见 [验收报告](VERIFICATION.md)。隔离后端不等于真实平台；K01–K05、独立第三方 provider 和生产门槛仍未通过。

## 1. 核心与提供方

| ID | 场景 | 必须观察到的行为 |
| --- | --- | --- |
| C01 | 正常文字请求 | 返回真实 provider 句柄、最终状态与对应结果 |
| C02 | 同键同载荷重复 | 同一命名空间内定位同一任务，无新增上游执行 |
| C03 | 同键不同载荷 | 明确冲突，不覆盖原请求 |
| C04 | 同键并发 | 一次上游接纳，或可追踪的同一进行中提交 |
| C05 | 重启后重试 | 找到原任务；不因进程重启重新执行 |
| C06 | 上游已接收但响应丢失 | 报告结果未知并恢复原请求；不换 key 重提 |
| C07 | 等待超时 | 区分等待超时与 provider 任务失败 |
| C08 | 取消与完成竞争 | 使用 provider 最终事实，不伪造已取消 |
| C09 | 未知状态 / 过大 / 畸形响应 | 安全失败，不产生伪成功或泄漏原始响应 |
| C10 | 不支持附件 / 流式 / 接管 | 明确 unsupported；能力声明与行为一致 |
| C11 | 进程关闭 / 恢复 | 停止新接纳，保留未确认任务的恢复线索 |
| C12 | 必要状态存储损坏或写入失败 | 拒绝无法保证一致性的执行，保留失败证据 |

## 2. 身份和权限

| ID | 场景 | 必须观察到的行为 |
| --- | --- | --- |
| A01 | 两个客户使用相同会话字符串 | 上下文与结果按 verified caller / channel namespace 隔离 |
| A02 | 两个企业出现同名 BOT / publication | 不能按名称混用发布授权 |
| A03 | 猜测或替换任务句柄 | 不返回另一调用者的状态和结果 |
| A04 | 只读凭据直接调用 submit/cancel | 服务端拒绝，不能仅隐藏入口 |
| A05 | 正文自报管理员 / system 角色 | 不获得高权限，不覆盖 BOT 策略 |
| A06 | 执行期间撤销授权 | 禁止新派发和迟到结果披露；如无法取消远端工作则明确记录 |
| A07 | 旧 grant 被改绑新 BOT / 组织 | 旧任务命名空间不被复用 |
| A08 | 身份服务不可用 | 依照已声明授权有效期拒绝或终止，不自动放行 |
| A09 | 恶意上游重定向 / 动态 URL | 不把凭据发送给任意目标 |
| A10 | 日志、错误、追踪和报告 | 不包含 token、客户正文、私有源码或系统提示 |

## 3. 协议与场景

| ID | 场景 | 必须观察到的行为 |
| --- | --- | --- |
| T01 | HTTP 提交、MCP 查询 | 相同主体与逻辑请求映射到同一任务 |
| T02 | MCP 提交、HTTP 取消 | scope、结果和取消语义一致 |
| T03 | 官方 MCP 客户端 | 完成实际握手与工具调用，不能只测试内部函数 |
| T04 | SSE / 断线 / 慢客户端 | 不伪造 token 流，不因重连重复提交；缓冲有界 |
| T05 | 协议版本不兼容 | 明确拒绝并给出不泄漏内部信息的错误 |
| K01 | Knocket 真实 Test Connection | 使用真实请求；不硬编码健康回复骗过检测 |
| K02 | 两个真实访客并发 | 回复归属正确、上下文独立 |
| K03 | 平台自动重试与断连 | 符合观察到的 key/timeout 合同；不推断平台一定传幂等键 |
| K04 | 人工接管 | 平台状态确实变化且人工可回复；迟到 BOT 回复不越过接管状态 |
| K05 | 平台默认字段 | 验证实际字段；不支持时明确失败并更新文档 |

| --- | --- | --- |

| O06 | 文档与支持矩阵 | 清楚区分计划、夹具验证、真实平台验收和生产部署 |

## 5. 阶段放行

- **设计仓库**：文档完整、许可和来源清楚；明确没有运行实现。
- **参考实现 alpha**：C/A/T 适用项通过，O01/O04/O05/O06 通过；不要求真实平台，必须说明夹具范围。
- **TeamBot 集成候选**：真实企业授权和隔离服务验证；模型夹具与真实供应商分别标注。
- **Knocket 试点通过**：K01–K05 有真实平台证据；未实现程序化接管时明确采用平台原生功能及其限制。
- **通用互操作候选**：O02/O03 通过，至少一个独立实现；不得把同一作者的两个同源 adapter 当作独立生态采用。
- **生产接受**：另有部署、备份恢复、监控、容量和运维责任验收。本项目的单元测试不能自动授予该状态。

每份报告包含源码 revision、contract/binding/SDK 版本、环境类型、命令、结果、测试数据性质和未覆盖项。原始带私有信息的日志只保存在授权的私有位置，公开报告仅放脱敏摘要。
